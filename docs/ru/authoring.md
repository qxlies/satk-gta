# Создание ассетов в Blender с satk

[English version](../en/authoring.md)

<!-- Страница для людей. Версия этого процесса для агентов — S25 в docs/agent/workflows.md. -->

satk позволяет ИИ-ассистенту (или вам) собрать новый ассет GTA San Andreas любого вида — машину, мотоцикл, лодку,
уличный проп, здание с его упрощённой дальней версией, интерьер, оружие, пикап или деталь тюнинга — в живой сессии
Blender, шаг за шагом, сравнивая его со стоковой игрой на каждом шаге. Результат — готовая папка Mod Loader.
Правила стиля, которым он следует, описаны в [sa-style.md](sa-style.md).

## Как это работает

- **Живая сессия Blender.** satk запускает свой Blender с отдельным профилем (ваши настройки и аддоны Blender не
  трогаются). Ассистент отправляет по одному шагу моделирования (добавить примитив с заданным числом сегментов,
  выдавить, добавить модификатор зеркала или фаски, поставить референсное фото...) и получает назад важные числа
  (треугольники, затенение, размер против стоковых моделей) и, по запросу, небольшую картинку.
- **Можно смотреть.** С `--gui` та же сессия открывает окно Blender; ваши изменения в нём тоже записываются.
- **Ничего не теряется.** Каждый шаг пишется в журнал, а сцена сохраняется контрольными точками, поэтому сборку
  можно повторить или откатить, а новая сессия ассистента может продолжить с того места, где остановилась прошлая.
- **Шаблоны вместо догадок.** Шаблон копирует имена фреймов, пустышки, настройки материалов и пропорции похожей
  стоковой модели (только имена и числа, никогда не её геометрию), а рядом с вашей моделью можно показать
  полупрозрачную стоковую.

## Перед началом

- Установлен Blender 5.1, и `satk doctor` показывает проверку `blender` как ok.
- Индекс стоковой игры построен (`satk index build`); эталон — чистая копия игры.
- Решите: заменить существующую модель или добавить новую. В стоковой игре нет свободных слотов машин, поэтому
  новые машины заменяют стоковую (или требуют лимит-аджастер).
- По желанию: референсные фото того, что вы хотите. Напишите короткое задание по шаблону
  [`asset-brief.md`](../agent/briefs/asset-brief.md); `satk style brief-check <brief.md>` укажет на формулировки,
  которые ведут к типичным ошибкам.

## Шесть этапов

| Этап | Что происходит | Что вы видите |
|---|---|---|
| G0 подготовка | папка проекта, уровень детализации (`sa_plus` по умолчанию), стоковая модель для сравнения, фото | числа класса |
| G1 болванка | грубая форма в правильном размере | картинка рядом с двумя стоковыми моделями класса примерно через 15 минут; скажите, что не так, сейчас, до деталей |
| G2 форма и затенение | окончательный силуэт, мягкое затенение с чёткими швами | вторая картинка: одобрите её до деталей и текстур |
| G3 детали | двери, капот, повреждённые версии, дальняя версия, коллизия | картинки повреждённого и упрощённого состояний |
| G4 текстуры | текстурные координаты на общих текстурах игры, свои небольшие «фотографические» текстуры | картинка в игровом виде и текстуры в настоящем размере |
| G5 экспорт | DFF, TXD и коллизия, проверка против стока, папка Mod Loader | отчёт и итоговая картинка |

На G1 и G2 ассистент останавливается и спрашивает вас: пропорции и силуэт дёшево исправить рано и дорого — потом.

## Команды

| Команда | Что делает |
|---|---|
| `satk asset init <папка> --kind automobile --like model:426` | начинает проект (`asset.json`: вид, уровень, решения, этапы) |
| `satk asset status` | короткая сводка проекта, чтобы продолжить с неё |
| `satk blender session start --gui` | запускает живую сессию Blender (с окном) |
| `satk blender call <метод>` | выполняет один шаг моделирования и возвращает его числа |
| `satk blender preview <файл или сессия> --lineup class` | одна картинка со стоковыми моделями класса в том же масштабе |
| `satk asset check <файл> --like model:426` | структура, числа и правила игры против стоковой модели |
| `satk kit export --replace model:426` | DFF, TXD, коллизия и папка Mod Loader |
| `satk col gen <dff>`, `satk fx2d copy` | коллизия для готовой модели, сделанной без набора шаблонов ([colgen.md](colgen.md)); фонари и другие эффекты, скопированные со стоковой модели ([fx2d.md](fx2d.md)) |

Эти команды приходят вместе с пакетами создания ассетов satk; `satk mcp ops create` покажет те, что есть в вашей
версии.

## После экспорта: посмотреть, затем проехать

Выгруженные файлы можно поставить рядом с картой во вьювере и быстро оценить в окружении (`satk view vehicle`,
`view place`, `view ped`; [viewscene.md](viewscene.md)), а затем попробовать в настоящей игре на закрытом тестовом
сервере: `satk ingame start`, затем `satk ingame check` ([ingame.md](ingame.md)). Игре нужна одноразовая настройка
клиента MTA от имени администратора; саму игру satk никогда не запускает.

## Установка результата

- Замена — это папка Mod Loader в `<workspace>\work\out\`: скопируйте её в папку `modloader` вашей игры (никогда не
  в чистую копию). README в папке перечисляет, что заменённая модель сохраняет (управляемость, список тюнинга,
  звуки).
- Новая модель (если есть свободный слот или стоит лимит-аджастер) получает свободный id и свои строки данных.
- Проверьте папку перед публикацией: `satk mod check <папка>`.

## Быстрый пример

```powershell
satk mcp ops create
satk help blender
```

Первая команда ищет среди всех операций satk слово «create»; вторая печатает заметки о Blender со списком
Blender-операций вашей версии.
