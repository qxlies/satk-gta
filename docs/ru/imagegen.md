# Imagegen: значки интерфейса через API картинок и запасной вариант на Pillow

[English version](../en/imagegen.md)

Пакет: `satk.imagegen`.

## Что это

`satk imagegen` делает небольшие элементы интерфейса (значки, плашки, точки статуса) для игры или инструмента:
просит у сервиса картинок плашку на однотонном пурпурном фоне, убирает фон (хромакей), обрезает, масштабирует,
проверяет результат и записывает, откуда взялся каждый файл. Без ключа API тот же набор рисуется в Pillow
(`satk imagegen placeholder`), поэтому проект не ждёт сеть. Всё пишется в `<workspace>/work/out/imagegen/`.

Набор `sae_v1` (вкладка Engine клиента sa-engine: четыре пресета дальности прорисовки, замок «ограничено
сервером» и три точки статуса) поставляется как спецификация; можно написать свою TOML-спецификацию.

## Быстрый пример

```powershell
satk imagegen icon-set --dry-run --only lock
```

Команда перечисляет запланированные запросы (3 кандидата замка, 3 вызова) и ничего не отправляет. Запасной вариант
ключа не требует:

<!-- docs-smoke: skip перезаписывает поставляемую папку заглушек и файлы происхождения; вручную запускать безопасно -->
```powershell
satk imagegen placeholder --only lock
```

Он рисует `lock_24.png` и `lock_48.png` в `<workspace>/work/out/imagegen/sae-v1/placeholder/` с файлами
происхождения; в каждой строке `valid: true`:

```json
{"ok":true,"cols":["file","size","valid","sha256","errors"],"rows":[["lock_24.png",24,true,"83a84b4deb3d6efc",""],["lock_48.png",48,true,"c062113fb04084ce",""]],"n":2}
```

Настоящий запуск (нужен ключ, тратит кредит API, только из командной строки):

<!-- docs-smoke: skip нужен ключ API, тратит кредит -->
```powershell
satk imagegen icon-set --max-calls 24
satk imagegen finalize --picks '{"classic":2,"balanced":4,"high":7,"extreme":11,"lock":13}'
```

`icon-set` пишет `contact_sheet.png` (кандидаты после хромакея, пронумерованы, по строке на значок) и
`contact_small.png` (самый маленький поставляемый размер, увеличенный); посмотрите их, затем `finalize` копирует
выбранные номера в `final` вместе с `PROVENANCE.md`.

## Команды

| Команда | MCP | Что делает |
|---|---|---|
| `satk imagegen generate "<prompt>" [--n 1-4] [--aspect 1:1] [--size 1K] [--model M] [--out DIR] [--name STEM]` | только CLI (согласие) | Обращается к сервису `n` раз; PNG и `.provenance.json` на каждую попытку, в том числе неудачную. |
| `satk imagegen key <png...> [--sizes 64,128] [--name STEM] [--strict]` | `satk_op` → `imagegen.key` | Хромакей, обрезка, поля, масштаб Ланцош, резкость (<= 48 px), проверка. |
| `satk imagegen icon-set [--spec sae_v1] [--candidates 3] [--max-calls 24] [--only lock] [--dry-run]` | только CLI (согласие) | Генерирует все значки спецификации, делает хромакей и проверку, пишет контакт-листы. |
| `satk imagegen placeholder [--spec sae_v1] [--only NAME] [--out DIR]` | `satk_op` → `imagegen.placeholder` | Рисует весь набор в Pillow; без сети и ключа. |
| `satk imagegen finalize [--spec sae_v1] [--picks JSON] [--use-placeholder NAMES]` | `satk_op` → `imagegen.finalize` | Собирает `final` из выбранных кандидатов, добавляет точки статуса, проверяет, пишет `PROVENANCE.md`. |

`generate` и `icon-set` доступны только из командной строки: они отправляют запрос стороннему сервису с ключом
пользователя и тратят кредит; агент сначала спрашивает пользователя. Параметр `--spec` — имя из поставки или путь
к `.toml`.

## Как это работает

**Ключ.** Ключ читается только из переменной окружения `SATK_IMAGEGEN_API_KEY`. Для него нет ни параметра, ни файла,
ни настройки; satk не печатает, не логирует и не сохраняет его. Каждая ошибка, файл происхождения и `repr`
проходят через очистку, которая маскирует и текст `Bearer ...`, а HTTP-клиент не идёт по перенаправлениям,
поэтому заголовок `Authorization` не может уйти с хоста сервиса. Адрес — `https://api.rout.my/v1/chat/completions`;
`SATK_IMAGEGEN_ENDPOINT` заменяет его (только https; http допустим для `localhost`).

**Запрос.** `POST` с телом `{"model", "messages": [{"role": "user", "content": PROMPT}], "modalities": ["image",
"text"], "image_config": {"aspect_ratio", "image_size"}}`; картинка — первый пригодный
`choices[0].message.images[i].image_url.url` (`data:image/...;base64,...`). Модель по умолчанию
`google/gemini-3.1-flash-image-preview` (около 14 с на изображение 1K), тайм-аут 120 с. В запросах нет снимков
игры и чужих материалов.

**Ошибки.** Код в конверте — один из зафиксированных кодов satk; код imagegen — первое слово сообщения и поле
`error.data.imagegen_code`:

| код imagegen | код конверта | Когда | Что происходит |
|---|---|---|---|
| `NO_API_KEY` | `NOT_READY` (выход 3) | переменная не задана или пуста | ничего не отправляется; используйте `placeholder` |
| `AUTH_FAILED` | `AUTH` | HTTP 401/403 | прогон сразу останавливается |
| `ENDPOINT_FAILED` | `EXTERNAL_TOOL` | 429, 5xx или сетевая ошибка дважды (одна повторная попытка через 10 с), другие ошибки HTTP | кандидат не удался; два подряд останавливают прогон |
| `NO_IMAGE` | `EXTERNAL_TOOL` | HTTP 200 без пригодного `images[]` | первые 300 символов текста ответа и `finish_reason` записываются в файл попытки; идёт следующий кандидат |

Каждый HTTP-запрос идёт в счёт `--max-calls` (повторная попытка тоже); при достижении предела остальные кандидаты
получают `SKIPPED`.

**Обработка** (`imagegen.key`, одни и те же шаги в каждом файле происхождения): хромакей `#FF00FF` (расстояние RGB
<= 90 прозрачно, от 90 до 130 линейный переход, краевые пиксели очищаются от фона и смешиваются с цветом плашки),
подавление розового (`min(r, b) > g` опускается до `g`), обрезка по рамке плашки, поля 4 %, масштаб Ланцош
(с предумноженной прозрачностью), нерезкая маска при <= 48 px, прозрачность ниже 4 обнуляется.

**Проверка.** Все четыре угловых пикселя с прозрачностью 0; нет пикселей с прозрачностью >= 16 и оттенком в пределах
15 градусов от пурпурного при насыщенности выше 0,5; плашка (прозрачность >= 128) занимает не менее 50 % холста.
Кандидат, не прошедший проверку, помечается `valid: false` и в `final` не попадает.

**Происхождение.** У каждого файла есть `<file>.provenance.json`: инструмент, хост сервиса, модель, запрос (и его
id), параметры, время UTC, текст ответа и причина завершения, SHA-256 исходного и итогового изображения, шаги и
результат проверки. `PROVENANCE.md` в `placeholder` и `final` содержит строку на каждый поставляемый файл: файл,
SHA-256, генератор, модель, id запроса, дата, шаги. Сгенерированное — наши собственные материалы; репозиторий
не коммитит PNG (их останавливает проверка ресурсов): они уходят в проект, который их поставляет.

**Спецификация** (`src/satk/imagegen/specs/sae_v1.toml`): фиксированный стилевой запрос с `{subject}` и `{accent}`,
значки (`id`, `subject`, `accent`, поставляемые `sizes`, форма заглушки) и точки статуса. Файлы называются
`<id>_<size>.png`: `preset_{classic,balanced,high,extreme}_{64,128}`, `lock_{24,48}`, `status_{ok,warn,error}_12`.

**Заглушка.** Плашка `#1F2428` с кольцом `#3A4148`; знак — светлый `#E8EAED` плюс акцент: от одного до четырёх
холмов (classic `#9AA0A6`, balanced `#34A853`, high `#4285F4`, extreme `#FB8C00` с маленьким городом) и пунктирная
линия обзора, которая с пресетом становится длиннее, либо замок `#FBBC04` (прямоугольник и дуга). Точки статуса —
плоские круги (`#34A853`, `#FBBC04`, `#EA4335`) с тёмным кольцом в 1 px. Рисование идёт с 8-кратной передискретизацией
и детерминировано: один и тот же вызов пишет те же байты.

## Ограничения и известные проблемы

- Модель каждый раз рисует чуть другую плашку (радиус углов, толщина кольца); выбирайте по контакт-листу, а
  `--use-placeholder lock` берите, если значок не читается в самом маленьком размере.
- Первый запрос может упереться в тайм-аут 120 с; тогда единственная повторная попытка даёт два вызова в счёте.
- `--out` и `--spec` принимают пути; результат должен лежать под `<workspace>/work` (защита записи отказывает в
  других местах).
- Нужны Pillow и numpy (`scripts\bootstrap.ps1 -Deps`).

## Python API

```python
from satk.imagegen.client import ImageClient
from satk.imagegen.keying import key_image, shrink, validate_image, load_image

master, steps = key_image(load_image("raw.png"))
icon, _ = shrink(master, 64)
assert validate_image(icon)["ok"]
client = ImageClient.from_env()          # NO_API_KEY, если переменной нет
attempt = client.generate("prompt")      # attempt.ok / attempt.code / attempt.image
```
