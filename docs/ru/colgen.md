# `satk col gen`: коллизия из моделей, проверки, поверхности

[English version](../en/colgen.md)

Пакет: `satk.colgen`. Сам писатель COL (`satk col write`, `satk col export`) описан на [странице rw](rw.md).

## Что это

Каждой модели, которую рисует игра, нужна модель коллизии, и сделать её руками в 3D-редакторе — самая долгая
часть мода с объектом, зданием или машиной. `satk col gen` строит её из DFF: бокс, несколько боксов, внешнюю
выпуклую оболочку, которая всегда содержит модель, упрощённый до бюджета граней меш или набор сфер как у машин
с замкнутым мешем тени. Материалы поверхностей (шаги, сцепление шин, эффекты попаданий) берутся по текстурам из
таблицы, выведенной из самой оригинальной игры, а байт освещения каждой грани — из prelit-цветов модели.
`satk col check` проверяет любой файл коллизии (сгенерированный, из мода или из игры). Игра только читается;
результат пишется в `<workspace>\work\out\colgen\`.

## Быстрый пример

```powershell
satk col gen model:1337 --mode hull
satk col gen infernus --out examples
satk col check BinNt07_LA.col
satk col surface ap_tarmac blendrock2grgrass my_wood_planks
```

Что возвращается (сокращено):

```json
{"ok":true,"cols":["name","mode","spheres","boxes","faces","shadow","surfaces","fit","file"],"rows":[["BinNt07_LA","hull",0,0,64,0,"PLASTIC_DUMPSTER:64","out 0.00 dev 0.04","<workspace>/work/out/colgen/BinNt07_LA.col"]],"dir":"<workspace>/work/out/colgen","models":1,"verified":true,"surface_from":{"table":"100%"}}
{"ok":true,"rows":[["infernus","spheres",20,0,0,300,"CAR:20","cover 55%","<workspace>/work/out/colgen/examples/infernus.col"]],"models":1,"verified":true,"surface_from":{"vehicle":"100%"}}
```

`fit`: `out` — насколько вершина модели выходит за коллизию (hull, box, boxes: 0 — модель внутри), `dev` —
насколько поверхность коллизии может отстоять от меша модели, `cover` — какую долю корпуса заполняют сферы.

## Команды

| Команда | MCP | Что делает |
|---|---|---|
| `satk col gen <dff\|folder\|img\|SID> [--mode auto\|box\|boxes\|hull\|mesh\|spheres\|bounds]` | — (через `satk_op`) | по одному COL3 на модель в `<work>/out/colgen/` (или один архив с `--archive`), перечитанный `satk.formats` (`verified`) |
| `satk col check <col\|folder\|img\|dff\|model:ID> [--sev info] [--fail-on error]` | — | таблица `model/sev/check/msg`, `summary` по худшей находке, `by_check` |
| `satk col surface [TEXTURE ...] [--txd NAME]` | — | что выберет `--surface auto` и почему; без текстур — 179 id и имён поверхностей |
| `satk col derive [--holdout 10] [--profile vanilla]` | — | пересобрать таблицу текстура -> поверхность по коллизиям профиля с отчётом точности |

Режимы `col gen` (по умолчанию `auto`):

| Режим | Коллизия | Бюджет |
|---|---|---|
| `box` | ограничивающий бокс сталкивающихся частей | — |
| `boxes` | боксы из воксельного разбиения, слитые и прижатые к мешу | `--max-prims 8` |
| `hull` | внешняя выпуклая оболочка: все вершины модели внутри | `--max-faces 64` |
| `mesh` | меш модели, сваренный по сетке COL (1/128 м) и упрощённый (квадрики ошибок) | `--max-faces 1000` |
| `spheres` | вписанные сферы, зеркальные слева/справа у машин, поверхность `CAR` и куски повреждений | `--max-prims 20` |
| `bounds` | без примитивов, только бокс и сфера границ (как у LOD-моделей в оригинале) | — |
| `auto` | машины: `spheres` + тень; > 25 м или > 2000 треугольников: `mesh`; иначе `hull` | |

Прочие параметры: `--shadow` / `--no-shadow` (замкнутый меш тени COL3, `--shadow-faces 300`), `--surface TARMAC`
(одна поверхность на всё), `--surface-rule "*grass*=GRASS_SHORT_DRY"` (сначала маски текстур),
`--exclude "*leaf*"` (имена частей или текстур, которые не учитывать), `--txd NAME` (контекст TXD для поверхностей),
`--version 2` (COL2), `--no-lighting` (свет граней 255), `--resolution N` (ячеек вокселей), `--archive mymod.col`,
`--out папка|файл.col`.

Коды `col check`: `parse`, `name`, `index`, `surface`, `box_inverted`, `sphere_radius`, `bounds`/`bsphere`
(ошибка больше 0,5 м, предупреждение больше 1 см), `face_groups` (ошибки); `limit` (больше самой крупной модели
оригинала: 5191 грань / 3408 вершин), `degenerate`, `no_face_groups`, `flags`, `shadow_open`, `shadow_winding`
(предупреждения); `duplicate`, `unused_vertices`, `empty` (info). На всём оригинальном `gta3.img` (8255 моделей)
находится 2 ошибки, обе — настоящие дефекты файлов игры.

## Как это устроено

- **Меш модели.** DFF декодируется с применением матриц фреймов (пространство модели, как в игре). Состояния
  повреждений и LOD (`*_dam`, `*_vlo`), геометрии без атомиков и колёса машин (коллизию колёс игра строит по
  дамми колёс) не сталкиваются.
- **Оболочка.** Опорные плоскости вершин (нормали граней модели, сфера Фибоначчи, оси) отсекают ограничивающий
  бокс: первой идёт плоскость, срезающая самый выступающий угол, пока углы не окажутся в пределах 4 мм от точной
  оболочки или не кончится бюджет граней. Вершины округляются по сетке COL наружу, поэтому модель остаётся внутри.
- **Меш.** Схлопывание рёбер по Гарланду-Хекберту; открытые края и границы между поверхностями держатся
  штрафными квадриками, перевороты и иглы запрещены, каждая грань сохраняет поверхность исходной грани модели.
- **Воксели.** Треугольники плотно семплируются, снаружи делается заливка; остальное — сплошное тело (сиденья
  машины не мешают). Из него строятся боксы, сферы и меш тени (замкнутая граница тела, сглаженная и упрощённая).
- **Обход граней.** Движок считает нормаль грани как `(C - A) x (B - A)` (`CColTrianglePlane`), то есть наоборот
  по сравнению с обходом RenderWare для рендера; грани пишутся именно так, а `col check` предупреждает о
  вывернутой тени.
- **Границы** охватывают все примитивы и сталкивающуюся геометрию модели: в оригинальных файлах бокс COL —
  ещё и бокс отсечения модели (99 % границ оригинала содержат DFF).
- **Поверхности.** `data/colgen/tex_surface.json` выведен из оригинальной игры: каждую из 1,18 млн граней
  коллизии сопоставили ближайшему треугольнику модели, получилась 6181 текстура с поверхностью большинства и
  2277 пар (TXD, текстура), где она другая (одна и та же трава в одном районе сочная, в другом сухая). Порядок
  поиска: `--surface-rule`, (TXD, текстура), текстура, ключевые слова (`data/colgen/keywords.json`), `DEFAULT`.
  На моделях, не вошедших в таблицу, 82 % граней получают поверхность оригинала (76 % без контекста TXD);
  сгенерированные меши выборки моделей совпадают с ближайшей гранью оригинала на 93 % граней.
- **Освещение.** Младшая (день) и старшая (ночь) тетрады байта освещения грани следуют линейной подгонке по
  prelit- и ночным цветам вершин (по 1,18 млн граней оригинала, средняя ошибка 1,7 из 15).
- Детерминированно: один и тот же вход даёт те же байты.

## Ограничения и известные проблемы

- Вершины COL2/3 — это `int16 / 128`: вершина меша или оболочки дальше 256 м от начала координат модели
  отклоняется (боксы и сферы хранятся во float и работают).
- Сферы подходят для замкнутых тел; тонкие или открытые модели (рама велосипеда, забор) получают низкий `cover`
  и заметку: для них берите `hull` или `boxes`.
- Куски повреждений машин определяются по бамперам и дверям под каждой сферой (совпадение с оригиналом 72 %).
- Таблица поверхностей знает имена текстур оригинала; новые текстуры уходят в ключевые слова, затем в `DEFAULT`.
  Проверяйте через `satk col surface` и переопределяйте через `--surface-rule`.

## Python-API

```python
from satk.colgen.build import GenOptions, generate
from satk.rw import col as COL

res = generate(dff_bytes, "mybarrel", opts=GenOptions(mode="hull", max_faces=48))
blob = COL.encode_model(res.model)
```
