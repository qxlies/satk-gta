## Форматы и данные игры

| Термин | Что это |
|---|---|
| **IMG** | архив игры (`models\gta3.img` и др.). У версии 2 (`VER2`) каталог лежит в начале файла; размеры — в секторах по 2048 байт. При совпадении имён побеждает архив, зарегистрированный первым |
| **DFF** | модель RenderWare: кадры (`frame`), геометрии, материалы, 2DFX-эффекты; в DFF машин есть ещё и коллизия |
| **TXD** | словарь текстур RenderWare; текстуры обычно сжаты в DXT1/DXT3 |
| **txdp** | «родительский» TXD: если текстуры нет в своём TXD, движок ищет её у родителя (а для машин — в `vehicle`) |
| **COL** | файлы коллизий (`COLL`, `COL2`, `COL3`, `COL4`); с моделью сопоставляются **по имени** |
| **IDE** | файл определений: номер модели, имя DFF, имя TXD, дальность прорисовки, флаги; секции `objs`, `tobj`, `anim`, `cars`, `peds`, `weap`, `hier`, `txdp`, `2dfx` |
| **IPL** | файл расстановки: где стоит какая модель. Бывают текстовые (`data\maps\…\*.ipl`) и бинарные (`bnry`, внутри IMG, `xxx_streamN`) |
| **inst** | одна запись расстановки: модель, позиция, кватернион, interior/area, ссылка на LOD |
| **LOD** | упрощённая модель, видимая издалека. У расстановки HD-модели есть ссылка на LOD-расстановку; LOD бинарного IPL указывает в текстовый IPL с тем же префиксом. LOD-моделям коллизия не нужна |
| **area / interior** | номер «мира» (0 — улица, остальные — интерьеры). В поле IPL младший байт — area, старшие биты — флаги |
| **DAT** | `data\default.dat`, `data\gta.dat`: какие IMG, IDE, IPL и COL загружать и в каком порядке; у SA-MP — файлы `.two` |
| **IFP** | пакет анимаций (`ANP3`/`ANPK`) |
| **ZON** | зоны карты (`map.zon`, `info.zon`): прямоугольники с кодами вроде `GAN1` (Гантон) или `VE` (Лас-Вентурас); игровые названия берутся из `text\american.gxt` |
| **2DFX** | эффекты, привязанные к модели: свет, частицы, точки входа и т. п. |
| **prelit** | цвета вершин, «запечённое» освещение; у зданий есть дневной и ночной наборы |
| **RW, RenderWare** | движок рендера GTA:SA; его файлы состоят из вложенных чанков `type/size/version` |
| **DXT1/3/5** | сжатые форматы текстур; в ванильной игре DXT5 нет вообще (64 штуки есть только в текстурах кнопок консолей оригинальной установки) |
| **кватернион IPL** | поворот хранится в файле «как есть», а мировой поворот — **сопряжённый**; satk отдаёт уже мировые `rz`/`q` |
| **`water.dat`, `timecyc.dat`, `handling.cfg`** | файлы данных, которые exe грузит по имени: полигоны воды, цвета по погоде и часу, физика машин; в индексе со схемы v3 (`water:`, `tcyc:`, `handling:`) |
| **exe HOODLUM** | наш эталонный `gta_sa.exe` 1.0 US (sha256 `a559aa77…cbd26`); адреса символов даны для него. Секция `.HOODLUM` — тела функций, перенесённые защитой, и переходы (`thunk`) на них |

## Понятия satk

| Термин | Что это |
|---|---|
| **SID** | стабильный строковый идентификатор объекта: `model:411`, `inst:lae2_stream0#4`, `fn:0x53bf09`. См. [ids.md](ids.md) |
| **рабочее пространство** | папка, где satk держит `satk.toml` и всё, что создаёт (`work\`); см. [install.md](install.md) |
| **профиль** | то, как игра видит конкретную установку: `game` (ваша папка с игрой), `vanilla` (чистая копия), `installed` (оригинал с модами), `samp` (оригинал с порядком архивов SA-MP). У каждого — свой файл индекса |
| **слой** | откуда пришёл файл: `vanilla`, `samp`, `modloader:<мод>`, `modded` |
| **активный / затенённый** | объект, который реально загрузит игра, и тот, что проиграл при совпадении имён (`@слой` в SID) |
| **блоб** | содержимое одной записи IMG или одного файла россыпью |
| **конверт** | форма любого ответа: `{"ok":true,…}` или `{"ok":false,"error":{…}}`; списки — `cols`/`rows` |
| **предупреждения (`warn`)** | необязательные предупреждения в успешном ответе: `MORE`, `LIMIT`, `INDEX_STALE`, `FALLBACK`… |
| **эталонные числа (`golden`)** | сколько текстур, моделей, расстановок… должно быть; с ними сверяются тесты (`tests/golden/*.json`) |
| **контакт-лист** | одна картинка с сеткой маленьких текстур и номерами; подписи — в JSON-легенде |
| **pix** | хэш пикселей текстуры: одинаковая картинка в разных TXD — один `pix:` и один PNG в кэше |
| **программный рендер** | собственный программный растеризатор превью моделей: без видеокарты и окна, повторяемый байт в байт |
| **экспорт «как в игре»** | DFF + TXD + COL модели отдельными файлами (режим `raw`, для DragonFF и модов) |
| **цель (`target`)** | куда смотрят `view_*`: `ariane` (вьювер), `game` (настоящая игра через форк MTA и ресурс `satk-agent`; запускается вручную), `mock` (синтетический тестовый мир) |
| **ID-буфер** | слой кадра, где в каждом пикселе записан ID нарисованного там объекта; с ним метки и доли точные |
| **метки (`marks`)** | номера, нарисованные на объектах кадра; легенда связывает номер с SID. С ID-буфером (нативный Ariane, `mock`) они точные, без него — `approx:true`: по сетке лучей `pick` |
| **pick** | «что под этим пикселем»: SID, модель, точка попадания. Нативный Ariane выбирает то, что нарисовано, адаптер старых сборок — по лучу коллизии; `link:"exact"` — цель сообщила IPL и индекс, `nearest` — объект найден в индексе по модели и позиции |
| **догрузка (`settle`, `settled`)** | ожидание, пока стриминг догрузит модели перед кадром; `settled:false` — кадр мог выйти «с дырами» |
| **снятый кадр (`cap:`)** | PNG и файл-спутник, записанные в базу заметок |
| **файл-спутник (`sidecar`)** | `.json` рядом с кадром: цель, поза, окружение, легенда, sha256; `satk view replay` повторяет кадр |
| **закладка (`bm:`)** | именованная поза камеры, например `grove_center` |
| **SAAP/1** | San Andreas Agent Protocol — наш протокол «глаз агента» (TCP 127.0.0.1, длина + JSON, токен, `caps`); наш форк Ariane говорит на нём сам |
| **ARIANE_IPC/1** | мост старых сборок Ariane без нативного эндпоинта; satk говорит с ним через адаптер |
| **возможности (`caps`)** | что умеет цель (`camera`, `capture`, `capture.ids`, `pick`, `env` …); если чего-то нет — `UNSUPPORTED` |
| **MCP** | Model Context Protocol: так ИИ-ассистент вызывает инструменты satk; `tools/list` — описание всех инструментов, которое модель читает в начале сессии |
| **symdb, sa-re** | символьная база `gta_sa.exe`: функции, глобальные переменные, vtable, патчи MTA с файлом и строкой |
| **уверенность (`confidence`)** | насколько надёжно адрес отнесён к функции: `high`, `medium` (между ними есть неименованный старт), `low`, `none` |
| **thunk** | короткий переход на настоящее тело функции (в `gta_sa.exe` — через `.HOODLUM`) |
| **HOOKPOS / MemPut** | способы, которыми MTA патчит `gta_sa.exe`: переход в свой код по адресу и запись байтов |
| **upstream / trunk / neon** | происхождение патча: ванильная MTA, наш форк `engine\mtasa`, форк Neon |
| **kb** | база знаний о внутренностях движка: функции, структуры, опкоды, проверенные факты (`satk kb`) |
| **задание Blender** | папка `work\blender\jobs\<id>\` с запросом, ответом, логом, `.blend` и PNG одного вызова |
| **objindex** | второй рендер Blender, где каждый объект своего цвета: из него получаются SID видимых объектов |
| **переносимый архив** | выпуск `satk-<version>-win64.zip` со своим Python; его папка и есть рабочее пространство (`portable.txt`) |
| **worktree** | отдельная рабочая копия репозитория `tools` на своей ветке (`work\wt\<id>`), чтобы агенты не мешали друг другу |

## Проекты и программы

| Термин | Что это |
|---|---|
| **MTA:SA** | Multi Theft Auto: San Andreas — мультиплеер с Lua; наш движковый форк сделан от `mtasa-blue` |
| **Neon** | форк MTA с движковыми возможностями; для нас — донор кода (только в GPL-форк) |
| **sa-engine** | название нашего проекта: форк MTA с правками движка |
| **реестр переносов (`ledger`)** | список кода, перенесённого из Neon (`engine\mtasa\docs\porting\neon-ledger.toml`) |
| **premake / MSBuild** | генератор проектов Visual Studio и сборщик; satk вызывает их напрямую, без IDE |
| **deps-lock** | `engine\deps-lock.json`: sha256 всех скачанных зависимостей сборки клиента; новый хэш — только явно |
| **Ariane** | редактор и вьювер карты GTA (на librw); наш форк — «быстрые глаза» агента |
| **librw** | открытая реализация RenderWare, на которой работает Ariane |
| **gta-reversed** | проект обратной разработки с исходниками функций GTA:SA; для нас — справочник адресов и кода (в git не попадает) |
| **Ghidra** | дизассемблер и декомпилятор; проект и экспорт для `gta_sa.exe` лежат в `work\re\ghidra\`; `satk re build --ghidra-functions` берёт из него точные границы функций, `satk re export ghidra` выгружает символы обратно |
| **SA-MP** | San Andreas Multiplayer; меняет порядок архивов и добавляет свои модели |
| **Mod Loader** | популярный ASI-плагин, который грузит моды из `modloader\<мод>\`, не трогая IMG-архивы; satk видит эти файлы как слои `modloader:<мод>` |
| **DragonFF** | аддон Blender для DFF/TXD/COL; satk вызывает его импортёры напрямую |
| **Codex / codexctl** | вторая модель для параллельных задач с проверкой у Claude (`agents\codex\`) |
