# Отчёт об ошибке: приватный локальный отчёт о проблемах satk

[English version](../en/bugreport.md)

Пакет: `satk.bugreport`. Команда: `satk bug-report`.

## Что это

`satk bug-report` собирает то, что нужно разработчику, чтобы понять проблему с satk, и пишет это в один
Markdown-файл в `work/out/bugreport/`. Он ничего никуда не отправляет: вы читаете файл и сами прикладываете его к
сообщению об ошибке или к письму. Пути, имена пользователя и компьютера, адреса почты и токены заменяются ещё до того, как вы
увидите текст, а файлов игры в отчёте нет.

## Быстрый пример

```powershell
satk bug-report --logs 1
satk bug-report --what "сборка индекса встаёт на 40%" --yes
```

Первая команда только показывает отчёт (в терминале спрашивает, записать ли его; `y` — записать); вторая пишет
сразу и сообщает куда:

```json
{"ok":true,"written":true,"path":"<workspace>/work/out/bugreport/satk-bug-report-20261005-120000.md",
 "sections":[["What happened",1],["Environment",6],["Network",1],["satk doctor",28],["Configuration",12],
 ["Game",2],["Operations",1],["Recent errors",8]],"redacted":{"game":5,"satk":2,"user":3,"workspace":21}}
```

## Команды

| Команда | MCP | Что делает |
|---|---|---|
| `satk bug-report [--what TEXT] [--logs N] [--out FILE] [--yes]` | `satk_op` | собрать, обезличить, показать; записать после «да» или с `--yes` |

- `--what` — что случилось, своими словами; текст попадает в начало отчёта (и обезличивается, как всё остальное).
- `--logs N` — сколько последних записей `work/logs/errors.log` включить (по умолчанию 3, `0` — ни одной).
- `--out FILE` — другое имя файла; папки, куда satk писать нельзя (игра), отклоняются (`PROTECTED_PATH`).
- `--yes` — записать, не спрашивая. Без него и вне терминала (ИИ-агент, скрипт) ничего не пишется: в результате
  лежит полный `text`, чтобы его сначала показать, а `next` подсказывает, как записать.

## Что входит в отчёт

Заголовки разделов в самом отчёте — английские (отчёт читает разработчик).

| Раздел | Содержимое |
|---|---|
| What happened | ваш текст из `--what` |
| Environment | версии satk и Python, версия Windows, кодировки, откуда запущен satk |
| Network | строка политики: `network: none by default` |
| satk doctor | все проверки со статусом, сообщением и способом исправить |
| Configuration | рабочее пространство, пути и откуда взят каждый, профили, переменные `SATK_*` |
| Game | издание, вариант `gta_sa.exe`, размер и SHA-256, недостающие файлы |
| Operations | сколько команд загрузилось, какие пакеты не импортировались (с ошибкой) |
| Recent errors | последние `--logs` записей `errors.log`, не больше 40 строк каждая |

Никогда не входят: файлы игры, их имена и списки, картинки, индекс, заметки, токены эндпоинтов вьювера и
переменные окружения, кроме `SATK_*`.

## Как устроено обезличивание

| Что найдено в тексте | Чем заменяется |
|---|---|
| папки игры (`game_root`, `installed`, чистая копия) | `<game>` |
| рабочее пространство | `<workspace>` |
| папка satk | `<satk>` |
| ваша папка профиля и папка профиля любого другого пользователя на любом диске | `%USERPROFILE%` |
| ваше имя пользователя и имя компьютера как отдельные слова | `<user>`, `<host>` |
| адреса почты | `<email>` |
| значения переменных `*TOKEN*`, `*SECRET*`, `*PASSWORD*`, `*API_KEY*`, `token=...`, `Bearer ...`, `sk-...`, `ghp_...` и похожие | `<redacted>` |

Пути находятся в любом написании (`\`, `/`, удвоенный `\\`, как в JSON, любой регистр). Имя пользователя, которое
является обычным словом (`User`, `Admin`), заменяется только внутри путей. В результате видно, сколько замен
каждого вида сделано (`redacted`). Прочитайте отчёт, прежде чем делиться им: обезличивание ловит обычные места, но
не все возможные.

## Приватность satk в целом

- satk не открывает соединений с интернетом и не отправляет телеметрию. Сокеты используются только на 127.0.0.1 —
  для вьювера, игры и SAAP. Загрузки бывают только в командах, которые вы запускаете сознательно:
  `satk engine setup` (зафиксированные зависимости сборки MTA), `satk dev release` (зафиксированные файлы с
  python.org и PyPI) и `scripts\bootstrap.ps1 -Deps` / `-Dev` (pip).
- `satk doctor` показывает это проверкой `network`; `satk doctor --deep` ещё и сканирует исходники satk и падает,
  если какой-то файл импортирует сетевой модуль, не будучи в списке разрешённых (`satk.runtime.network`).
