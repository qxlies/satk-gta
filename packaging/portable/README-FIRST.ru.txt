satk - San Andreas ToolKit (переносимая сборка для Windows 10/11, 64 бита)
==========================================================================

satk строит индекс вашей GTA San Andreas (PC) и помогает вам или ИИ-ассистенту находить
и разбирать модели, текстуры, расстановку объектов на карте и адреса крэшей. Ничего не
нужно устанавливать, права администратора и интернет не нужны. Игра только читается;
satk пишет только в эту папку.

1. Разблокировать и распаковать
   Windows помечает скачанные из интернета файлы и потом спрашивает при каждом запуске.
   До распаковки: правый клик по zip > Свойства > галочка «Разблокировать» > ОК.
   Распакуйте в свою папку, например D:\satk (кириллица и пробелы в пути не мешают).
   Не в папку игры и не в Program Files.

2. Запуск
   Двойной клик по «Запустить satk.cmd». При первом запуске выполнится «satk init»:
   он ищет папку игры (реестр, Steam, обычные места). Если не нашёл:
       satk init --game "C:\Games\GTA San Andreas"

3. Индекс игры (около минуты) и поиск
       satk index build
       satk asset find grove
       satk help --ru

4. Подключить ИИ-ассистента (MCP)
       satk mcp config
   печатает настройки сервера; satk-mcp.cmd запускает сервер для клиентов, которым нужна
   одна команда.

5. Если что-то не так
       satk doctor
   проверяет установку и для каждой проблемы говорит, как её исправить.

Документация: docs\ru\ (по-русски), docs\en\ (по-английски). История версий: CHANGELOG.md.
Страница проекта, новые версии и сообщения о проблемах: https://github.com/qxlies/satk-gta
(satk bug-report пишет обезличенный локальный отчёт, его можно приложить к сообщению о проблеме).
Проверка скачанного: SHA256SUMS.txt рядом с zip; в PowerShell: Get-FileHash <zip>.
Обновление: распакуйте новую версию в новую папку и перенесите туда work\ и satk.toml.
Удаление: удалите эту папку.
