Third-party notice: CrashInfo crash list (GTA San Andreas 1.0 US, English)
==========================================================================

What: the community list "crash address -> problem -> solution" of the CrashInfo
plugin for GTA San Andreas 1.0 US (English edition), used by `satk crash analyze`
(keys "known" and "solution") and `satk crash known`.

File in satk: data/crashlist/gta-sa-10us-en.txt (provenance: data/crashlist/source.json).
Source: https://github.com/JuniorDjjr/CrashInfo
        Lists/GTA-SA-10US/EN-CrashList.txt, revision
        440f9a516b5726d89f7c2e30093f93bf6d56fae6 (2026-10-03), list dated 2026-10-02,
        sha256 5461f5e54eb1fa145ba8664addf3bb448b6242945e88211abbe968f9e85b99be.
Changes: none. The file is stored byte for byte; satk parses it at run time and
