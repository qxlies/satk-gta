# Files of the development repository that never go public: `satk dev export-public` leaves them out of the
# public snapshot, and `satk dev release` leaves them out of the zip, the wheel and the sdist.
#
# Patterns follow .gitignore: one per line, "#" starts a comment, "!" re-includes, a "/" at the start or in
# the middle anchors the pattern to the repository root, "*" and "?" and "[...]" match inside one name,
# "**" matches across folders, a trailing "/" means a folder. The last matching line wins.
#
# Lines starting with "@allow" are audit exceptions, not patterns:
#   @allow <rule> <path pattern> [<regex the finding's text must match>]
# Rules: machine-path, plan-ref, email, secret, private-repo, asset, large-file, dangling-ref.

# Review notes of the development process (internal task ids, not needed by any test).

# Compares the index schema with the maintainers' design notes, which exist only in the development workspace.
/tests/index/test_ddl_spec.py
